# Painel Financeiro

Painel administrativo desenvolvido para apoiar a rotina financeira do Colégio Fantástico.

**Versão em produção:** https://painel-financeiro-colegio-fantastic.vercel.app

## Escopo

O painel reúne ferramentas para documentos e organização financeira. Não trata dados de alunos nem mensalidades. Os arquivos dos conversores são processados localmente no navegador.

## Código e linguagens

Os arquivos completos da aplicação ainda não foram organizados neste repositório. Por isso, o GitHub não identifica linguagens a partir da fonte aqui disponível.

## Manutenção

Usar dados fictícios em demonstrações e não armazenar documentos financeiros, credenciais ou dados pessoais no GitHub. Antes de alterar o site, validar os recursos de conversão e o acesso ao painel publicado.
