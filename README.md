Registro do painel administrativo criado para apoiar a rotina financeira do Colégio Fantástico.

**Versão em produção:** https://painel-financeiro-colegio-fantastic.vercel.app

## Escopo

O sistema reúne ferramentas de documentos e apoio à organização financeira. A aplicação não trata dados de alunos nem mensalidades.

## Estado do repositório

Os arquivos completos da versão publicada ainda não foram organizados neste repositório. O GitHub não consegue calcular linguagens sem o código-fonte. A publicação e os dados da aplicação não são alterados por este README.
