Registro do painel administrativo desenvolvido para apoiar a rotina financeira do Colégio Fantástico.

**Versão em produção:** https://painel-financeiro-colegio-fantastic.vercel.app

## Escopo

O painel reúne ferramentas para documentos e organização financeira. Não trata dados de alunos nem mensalidades.
